# Website MTsN 2 Sukoharjo
Buka `index.html` di browser. Tanpa build, tanpa dependensi.

## Mengganti logo dan foto
- Logo: timpa `assets/img/logo-mtsn2skh.svg` (atau ganti `src` di index.html ke berkas .png/.webp).
- Foto kegiatan dan lomba: simpan foto asli di `assets/img/`, lalu ubah `src` di `GALERI` pada `js/data.js`.
- Foto kepala madrasah: timpa `assets/img/kepala-madrasah.svg`.

## Mengisi konten
Semua prestasi, agenda, galeri, fasilitas, dan berita ada di `js/data.js`. Nama siswa tidak ditampilkan (PRD 7.1).
